🚀 HOW TO START
═════════════════════════════════════════════════════════════════

Step 1: Create Vector Index (first time only)
  $ python ingest_and_run.py
  (Type 'exit' when done)

Step 2: Start Streamlit UI
  $ python run_streamlit.py
  
  OR use entry point:
  $ python ingest_and_run.py ui

Step 3: Open Browser
  http://localhost:8501

Step 4: Ask Questions!
  Use tabs to explore features
  Click sample questions to try
  View history and export results

═════════════════════════════════════════════════════════════════

🔧 CONFIGURATION
═════════════════════════════════════════════════════════════════

Required (.env):
  OPENAI_API_KEY=sk-your-key-here

Optional (.env):
  OPENAI_CHAT_MODEL=gpt-4o-mini
  OPENAI_EMBED_MODEL=text-embedding-3-small
  RAG_TOP_K=5
  RAG_MAX_CONTEXT_CHARS=12000

In UI:
  • Adjust Top-K with slider (1-20)
  • View all settings in Settings tab
  • Changes apply immediately

🐛 TROUBLESHOOTING
═════════════════════════════════════════════════════════════════

"System not ready"
→ Run: python ingest_and_run.py

"Index not found"
→ Run: python ingest_and_run.py

"OPENAI_API_KEY not configured"
→ Edit .env, add key from:
  https://platform.openai.com/api-keys

"Streamlit not found"
→ pip install streamlit

"Slow performance"
→ Close other apps, check internet
→ API latency depends on OpenAI
